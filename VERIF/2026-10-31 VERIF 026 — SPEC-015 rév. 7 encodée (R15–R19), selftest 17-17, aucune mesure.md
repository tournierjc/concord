## 1. Ce qui change dans mes rapports, point par point

### 1.1 ACo-9 F2 — l'étiquette change, la valeur non (C6 fermé, AD-26 §1)

Un consommateur à 2500 ms ne se rapporte **plus** « F1 vert / F2 hors canon, arbitrage C6 » et **jamais** comme
un vert ou un rouge de rendu. Forme canonique, désormais exigée littéralement par la garde :

```
ACo-9 F2 constante=SPEAKING_RELAY_STALE_MS valeur=2500 keepalive=1000 ratio=… \
  verdict=NON-CONFORME-C6 etiquette="non conforme — défaut de valeur, corrigé par une constante (C6, AD-26)"
```

* `verdict=NON-CONFORME-C6` est le seul jeton admis ; `VERT`, `ROUGE`, `PASS`, `FAIL` sur une ligne F2 sont des rejets
  (F2 est une **valeur**, pas une mesure de rendu).
* L'étiquette doit être le dernier champ de la ligne, mot pour mot (tiret cadratin, virgule, parenthèses comprises).
  Toute variante — « hors canon », « arbitrage C6 », « défaut de valeur (C6, AD-26) » sans « corrigé par une
  constante » — est un rejet motivé.
* Budget d'ACo-9 inchangé : **2000 ms + 1 trame**. C6 est fermé sans dérogation : la garde refuse donc aussi
  qu'une valeur 2000 porte une étiquette de non-conformité (faux défaut).
* Vérifié dans l'arbre à cette date : `SPEAKING_RELAY_STALE_MS = 2000` (`src/renderer/speaking-surface.ts:39`),
  `SPEAKING_KEEPALIVE_MS = 1000` (`src/renderer/speaking-relay.ts:31`). Une seule occurrence de « 2500 » subsiste
  dans `src/renderer/` (`speaking-surface.ts:37`) et c'est le commentaire qui **rejette** 2500 — la divergence
  « deux commentaires citant AD-23 D4.2 » que j'avais signalée dans VERIF-024 rév. 3 n'existe plus dans l'arbre.
  Commande : `grep -rn 2500 src/renderer/*.ts src/renderer/*.tsx`

### 1.2 ACo-8, ACo-9, ACo-16 — « non exécutables », pas « gelés »

Statut machine imposé aux trois critères : `statut=non-executable-relais` **avec un motif nommant T23**
(p. ex. `raison=relais-non-cable-T23`). Le mot « gelé » sur l'un de ces trois est un rejet ; un statut
`non-executable-relais` dont le motif ne nomme pas T23 est également un rejet (motif périmé).

État constaté, qui justifie le statut : `src/renderer/speaking-relay.ts` existe mais **n'est importé par aucun
point d'entrée d'overlay** — `grep -c 'speaking-relay' src/renderer/overlay-entry.tsx` → **0**. Sans ce câblage,
aucun rendu d'overlay n'est observable : ACo-16 ne peut pas compter.

ACo-16 tel qu'encodé (garde-vie, 3 s à 1 Hz sur état inchangé) :

```
ACo-16 statut=PASS variante=garde-vie-seule duree_s=3 garde_vie_hz=1 messages=3 compte=rendus rendus_overlay=0
```

* `compte=rendus` obligatoire : si le journal dit `compte=messages`, la preuve est vide → rejet.
* garde-vie seule ⇒ `rendus_overlay` **doit** valoir 0 (un rendu par message = la garde dessine = défaut).
* variante `re-rendu-par-message` ⇒ le compteur doit voir des rendus (≥ 1, 3 attendus) **et** le verdict doit être
  `ROUGE` : un tel journal coché `PASS` est un rejet. Les deux sens sont donc falsifiables.

### 1.3 ACo-14 / ACo-15 — gelés **pour une mesure**, C5 tranché (a)

Statut `gele` conservé, mais un critère gelé ne porte **aucun** verdict (vert ou rouge) — la garde rejette
`statut=gele` accompagné d'un `verdict=`. C5 est arbitré : **(a) `backgroundThrottling: false`**, une ligne
`src/main/index.ts` sur la fenêtre portant la boîte aux lettres. Une ligne de mesure doit donc nommer
`c5=backgroundThrottling-false borne=boite-aux-lettres` ; `c5=Timers` est un rejet (Timers est le **repli (b)**,
pas l'option par défaut), et une mesure sans `c5=` est un rejet.

Sorties exigées, seuils encodés :

| Sortie | Seuil | Règle |
|---|---|---|
| extinction fenêtre réduite | ≤ 2000 ms + 1 trame → **≤ 2016 ms** | `extinction_ms=2400` → rejet |
| rendus overlay | ≤ **2/s** | `rendus_par_s=3` → rejet |
| mesure datée | `date=<ISO>` | mesure non datée non recevable |

Repli autorisé **seulement** après échec nommé : `repli=Timers` sans champ `echec=` est un rejet.
ACo-15 reste **ni vert ni rouge** jusqu'à la mesure — aucun de mes rapports ne le cochera avant.

État constaté : `grep -n backgroundThrottling -r src` → **aucune occurrence**. La ligne C5(a) n'est pas posée :
ACo-14/ACo-15 restent donc gelés pour mesure, et ce motif est imprimé par le script.
